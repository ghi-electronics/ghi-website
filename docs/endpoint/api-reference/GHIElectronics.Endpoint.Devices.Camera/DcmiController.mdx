# DcmiController Class

**Package:** `GHIElectronics.Endpoint.Devices.Camera`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Camera`

Base controller for the board's parallel camera-interface port. Reserves the camera data and sync pins, drives the pixel clock, loads the backing kernel module, and exposes single-frame capture and streaming. Concrete sensor drivers derive from this type.

```csharp
public abstract class DcmiController : IDisposable
```

## Constructors

### DcmiController(string devicePath)

```csharp
public DcmiController(string devicePath)
```

Reserves the camera-interface pins, starts the pixel clock, and loads the backing capture driver. The V4L2 node is not opened until `DcmiController.Open` is called.

| Parameter | Type | Description |
|---|---|---|
| `devicePath` | `string` | V4L2 device node for the capture, defaulting to `/dev/video0`. |

## Methods

### Capture()

```csharp
public byte[] Capture()
```

Captures a single frame synchronously and returns it in the format set by `CameraConfiguration.ImageFormat`. Throws if `DcmiController.Setting` is unset, the device is not open, or a video stream is already running.

**Returns** `byte[]`: frame bytes, or `null` if the sensor returned no valid JPEG.

### Close()

```csharp
protected void Close()
```

Stops streaming (if active) and closes the V4L2 device. Safe to call when already closed.

### Dispose()

```csharp
public void Dispose()
```

Closes the device, releases the camera-interface pins, stops the pixel clock and unloads the backing capture driver.

### GetResolution()

```csharp
public string[] GetResolution()
```

Lists every `WIDTHxHEIGHT` resolution the capture driver reports from `v4l2-ctl --list-formats-ext`, or `null` if none are found.

**Returns** `string[]`

### Open()

```csharp
protected void Open()
```

Opens the V4L2 device for capture. Throws if the device is already open or the node does not exist.

### VideoStreamStart()

```csharp
public void VideoStreamStart()
```

Begins continuous capture on a background task; each frame is delivered through `DcmiController.FrameReceived`. Throws if `DcmiController.Setting` is unset or the device is not open. Call `DcmiController.VideoStreamStop` to end streaming.

### VideoStreamStop()

```csharp
public void VideoStreamStop()
```

Signals the streaming worker to stop and blocks until it has exited.

## Events

### FrameReceived

```csharp
public event FrameReceivedEventHandler FrameReceived
```

Fires on the streaming worker thread for every frame captured by `DcmiController.VideoStreamStart`. Not raised by `DcmiController.Capture`.
