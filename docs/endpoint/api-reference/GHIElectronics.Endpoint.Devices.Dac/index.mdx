<h1 className="api-package-heading">GHIElectronics.Endpoint.Devices.Dac</h1>

The DAC driver for Endpoint.

## Classes

| Class | Summary |
|---|---|
| [DacChannel](./DacChannel.mdx) | A DAC channel opened with `DacController.OpenChannel`. `DacChannel.WriteValue` takes a raw value, `DacChannel.WriteValue` a 0.0 to 1.0 part of the range. |
| [DacController](./DacController.mdx) | Endpoint's DAC (analog outputs), with the same API as TinyCLR. Opening a channel makes its pin an analog output; closing it switches the output off and puts the pin back as it was. |
