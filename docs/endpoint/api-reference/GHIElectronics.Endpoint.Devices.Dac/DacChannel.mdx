# DacChannel Class

**Package:** `GHIElectronics.Endpoint.Devices.Dac`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Dac`

A DAC channel opened with `DacController.OpenChannel`. `DacChannel.WriteValue` takes a raw value, `DacChannel.WriteValue` a 0.0 to 1.0 part of the range.

```csharp
public class DacChannel : IDisposable
```

### Dispose()

```csharp
public void Dispose()
```

### WriteValue(double ratio)

```csharp
public void WriteValue(double ratio)
```

Sets the output to a part of the range: 0.0 is 0 V, 1.0 is 3.3 V

### WriteValue(int value)

```csharp
public void WriteValue(int value)
```
