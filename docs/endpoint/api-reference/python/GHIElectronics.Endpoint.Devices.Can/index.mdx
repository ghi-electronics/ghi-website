<h1 className="api-package-heading">GHIElectronics.Endpoint.Devices.Can</h1>

CAN for Endpoint. CanController.Initialize (in Endpoint.Core) sets a port up, then CanRaw sends and receives frames.

## Classes

| Class | Summary |
|---|---|
| [CanRaw](./CanRaw.mdx) | A raw CAN interface on a canN device. Send and receive `CanFrame` messages, set filters. |
| [CanFrame](./CanFrame.mdx) | A single CAN message: 11 or 29-bit identifier and up to 8 data bytes. |
