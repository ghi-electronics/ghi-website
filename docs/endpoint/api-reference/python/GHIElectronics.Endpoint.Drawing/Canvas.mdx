# Canvas Class

**Package:** `GHIElectronics.Endpoint.Drawing`<br/>**Module:** `GHIElectronics.Endpoint.Drawing`

A pixel buffer plus the primitives to draw into it. Pick the size and `PixelFormat` at `Create` time; when done, hand `Buffer` to whichever device accepts bytes.

```python
class Canvas: ...
```

### Example

```python
canvas = Canvas.Create(240, 320, PixelFormat.Rgb565)
canvas.Clear(Color.Black)
canvas.DrawLine(10, 10, 230, 310, Color.Red, 2)
canvas.FillCircle(120, 160, 40, Color.Blue)
canvas.DrawText("Hello Endpoint", font, 10, 30, 20, Color.White)
spi.Write(canvas.Buffer)
```

### DrawImage(source, x, y, width=None, height=None, pixel_format=None)

```python
def DrawImage(self, source, x: int, y: int,
              width: int = None, height: int = None, pixel_format: int = None) -> None:
```

Blit an image into this canvas at (x, y). Overloads:

- `source` is an `Image`: use its cached decoded pixels (fast path).
- `source` is bytes-like and the other args are `None`: treat as encoded file bytes (JPG / PNG / BMP / GIF / TGA), decode once and blit.
- `source` is bytes-like and `width`/`height`/`pixel_format` are given: treat as a raw pixel buffer of that size and format.
