<h1 className="api-package-heading">GHIElectronics.Endpoint.Drawing</h1>

Off-screen 2D drawing primitives for Endpoint: `Canvas`, `Color`, `Font`, `Image`, `PixelFormat`. Pure pixel drawing, independent of the LVGL-backed UI widget library.

Install:

```bash
pip install GHIElectronics.Endpoint.Drawing
```

Import:

```python
from GHIElectronics.Endpoint.Drawing import Canvas, Color, Font, Image, PixelFormat
```

## Classes

| Class | Summary |
|---|---|
| [Canvas](./Canvas.mdx) | A pixel buffer plus the primitives to draw into it. Pick the size and `PixelFormat` at `Create` time; when done, hand `Buffer` to whichever device accepts bytes. |
| [Font](./Font.mdx) | A TrueType / OpenType font loaded from raw file bytes. Pass to `Canvas.DrawText` to render strings at any pixel size. |
| [Image](./Image.mdx) | A decoded image, ready to blit into a `Canvas`. Decoding (JPEG / PNG / BMP / GIF / TGA) happens once at `Load`. |
| [Color](./Color.mdx) | A 32-bit color with 8 bits each of alpha, red, green, blue. |

## Enum-like

| Class | Summary |
|---|---|
| [PixelFormat](./PixelFormat.mdx) | Pixel layout of a `Canvas` buffer. |
