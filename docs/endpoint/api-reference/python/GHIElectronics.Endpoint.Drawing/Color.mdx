# Color Class

**Package:** `GHIElectronics.Endpoint.Drawing`<br/>**Module:** `GHIElectronics.Endpoint.Drawing`

A 32-bit color with 8 bits each of alpha, red, green, blue. `Canvas` maps it to its `PixelFormat` at draw time.

```python
class Color: ...
```

## Constructors

### Color(r, g, b, a=0xFF)

```python
def __init__(self, r: int, g: int, b: int, a: int = 0xFF):
```

## Properties

### R

```python
R: int
```

Red component, 0..255.

### G

```python
G: int
```

Green component, 0..255.

### B

```python
B: int
```

Blue component, 0..255.

### A

```python
A: int
```

Alpha, 0 (transparent) .. 255 (opaque). Only Argb8888 canvases use it.
