# SerialPortController Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Chip-neutral entry point for UART / serial-port setup. Call once before using `System.IO.Ports.SerialPort`: it muxes the TX/RX pins (plus RTS/CTS when flow control is on) and makes `/dev/ttyS*` usable.

