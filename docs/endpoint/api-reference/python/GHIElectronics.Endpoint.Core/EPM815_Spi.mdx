# Spi Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The SPI buses bundled with EPM815, for .NET's `System.Device.Spi`. `Spi.Initialize` connects the bus's pins and loads the SPI driver; then use `SpiDevice` as usual. Each constant is the bus number for `SpiConnectionSettings` (`/dev/spidevN.0`), fixed by the firmware. Chip select is not driven by the bus: use any GPIO pin.

```python
class Spi: ...
```

## Methods

### Initialize(int bus, int bufferSize)

```python
@staticmethod
def Initialize(bus: int, bufferSize: int) -> None:
```

Connects the bus's pins and loads the SPI driver (spidev) if needed

| Parameter | Type | Description |
|---|---|---|
| `bus` | `int` | Spi1, Spi4 or Spi5 |
| `bufferSize` | `int` | The largest transfer in bytes. It is set when the driver loads, so for all buses: the first Initialize after boot decides it. |

### UnInitialize(int bus)

```python
@staticmethod
def UnInitialize(bus: int) -> None:
```

Gives the bus's pins back, as they were before Initialize
