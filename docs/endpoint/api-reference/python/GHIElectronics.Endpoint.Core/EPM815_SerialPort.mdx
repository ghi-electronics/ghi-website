# SerialPort Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The serial ports (UARTs) bundled with EPM815, for .NET's `System.IO.Ports`. `SerialPort.Initialize` connects the port's pins; then use `SerialPort` as usual.

```python
class SerialPort: ...
```

## Methods

### Initialize(string portName, bool enableHardwareFlowControl)

```python
@staticmethod
def Initialize(portName: str, enableHardwareFlowControl: bool) -> None:
```

Connects the port's TX and RX pins, and RTS and CTS for hardware flow control

| Parameter | Type | Description |
|---|---|---|
| `portName` | `string` | Uart1 ... Uart8 |
| `enableHardwareFlowControl` | `bool` | Also connect RTS and CTS (UART1, 2, 3 and 7) |

### UnInitialize(string portName)

```python
@staticmethod
def UnInitialize(portName: str) -> None:
```

Gives the port's pins back, as they were before Initialize

### UnInitialize(string portName, bool enabledHardwareFlowControl)

> ⚠️ **Obsolete.** The flow control setting is remembered from Initialize: use UnInitialize(portName)
