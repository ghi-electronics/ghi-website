# PwmController Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Chip-neutral entry point for PWM setup. Call once before using `Pwm.PwmChannel`: it brings up the PWM channel and muxes its pin.

