# Pwm Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

PWM pins bundled with EPM815, for .NET's `System.Device.Pwm`. `Pwm.Initialize` connects the pin to its timer; `Pwm.GetChipId` and `Pwm.GetChannelId` give what `PwmChannel` needs. Channels of one timer share its frequency.
