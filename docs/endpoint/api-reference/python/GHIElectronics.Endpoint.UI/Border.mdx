# Border Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

Container with WPF-style `Border.Thickness`, `Border.BorderBrush`, `Border.CornerRadius`, and `Border.Padding`. Children are positioned relative to this border, same as `UI.Container`. Background is set via the inherited `Widget.BackgroundColor`.

```python
class Border(Widget): ...
```

## Constructors

### Border(Widget parent)

```python
def __init__(self, parent: Widget):
```

Create a border inside `parent`.

| Parameter | Type | Description |
|---|---|---|
| `parent` | `Widget` | Containing widget. |

## Properties

### BorderBrush

```python
BorderBrush: int  # @property / @setter
```

Border line color as `0x00RRGGBB`. Getter returns the last value set (LVGL has no read-back).

**Returns** `uint`

### CornerRadius

```python
CornerRadius: int  # @property / @setter
```

Corner radius in pixels (0 = sharp corners). Getter returns the last value set (LVGL has no read-back).

**Returns** `int`

### Padding

```python
Padding: int  # @property / @setter
```

Inner padding in pixels between the border and child widgets. Getter returns the last value set (LVGL has no read-back).

**Returns** `int`

### Thickness

```python
Thickness: int  # @property / @setter
```

Border line thickness in pixels. Getter returns the last value set (LVGL has no read-back).

**Returns** `int`
