# Screen Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

A top-level container with no parent. Multiple screens can exist at once; only one is active at a time. Call `Screen.Load` to make this the currently-displayed screen.

```python
class Screen(Widget): ...
```

### Active
