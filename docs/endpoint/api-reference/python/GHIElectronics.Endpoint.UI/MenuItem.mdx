# MenuItem Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

Handle to a menu item. For a leaf item (`Menu.AddItem`) subscribe to `MenuItem.Clicked`. For a dropdown parent (`Menu.AddDropdown`) subscribe to `MenuItem.ValueChanged` and read `MenuItem.Selected` to find out which sub-item the user picked.

```python
class MenuItem: ...
```

## Properties

### Selected

```python
Selected: int  # @property
```

For dropdown items: 0-based index of the sub-item the user picked. Returns -1 if this is a leaf item (no sub-items).

**Returns** `int`

## Events

### Clicked

```python
Clicked  # += / -= handler
```

Fires when a leaf item is tapped. Runs on the UI thread.

### ValueChanged

```python
ValueChanged  # += / -= handler
```

Fires when the user picks a sub-item from a dropdown item. Runs on the UI thread.
