# Grid Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

WPF-style Grid with ColumnDefinitions + RowDefinitions. Call `Grid.SetDefinitions` once with the column + row sizes, then call `Grid.SetCell` on each child. Sizes: positive = fixed pixels; 0 or negative = star (-1 = "*", -2 = "2*", ...).

```python
class Grid(Widget): ...
```

### SetDefinitions(int[] columns, int[] rows)

```python
def SetDefinitions(self, columns: list[int], rows: list[int]) -> None:
```

Define column and row sizes. Positive values are fixed pixel widths; a negative value `-n` is a star share of weight `n` (`-1` = `*`, `-2` = `2*`, ...). Zero is treated as star.

| Parameter | Type | Description |
|---|---|---|
| `columns` | `int[]` | Column size definitions, left to right. |
| `rows` | `int[]` | Row size definitions, top to bottom. |
