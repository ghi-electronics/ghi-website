# StorageController Class

**Package:** `GHIElectronics.Endpoint.Devices.Storage`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Storage`

The SD card slot or the USB drives. Events come on the library's storage thread. A drive that is pulled out is unmounted by the library. The SD card is at `/media/sd/`; USB drives get the first free `/media/usbN/`, as Windows gives the first free drive letter. A controller stays alive until it is disposed.

