# AdcController Class

**Package:** `GHIElectronics.Endpoint.Devices.Adc`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Adc`

Endpoint's analog inputs, for .NET's `System.Device.Analog`. The pin argument is a per-board `Adc.Pin` constant (for example `EPM815.Adc.Pin.PA0` or `EPN256.Adc.Pin.PB0`). Opening a pin makes it an analog input; closing it returns the pin as it was. The inputs measure 0 V to `AnalogController.VoltageReference`.
