# Keyboard Class

**Package:** `GHIElectronics.Endpoint.Devices.UsbHost`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.UsbHost`

Allows a usb device to be used as a keyboard.

```python
class Keyboard(BaseDevice): ...
```

### Remarks

The CharUp and CharDown events are only fired when a given key press has a corresponding ASCII key code (a US keyboard; Ctrl+A to Ctrl+Z give 1 to 26). A key held down gives one KeyDown. The events come on the keyboard's own thread.

## Events

### CharDown


Fired when a key is pressed and it can be converted to ASCII.

### CharUp


### KeyDown

