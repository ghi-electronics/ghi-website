# UsbConnectionChangedEventHandler Delegate

**Package:** `GHIElectronics.Endpoint.Devices.UsbHost`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.UsbHost`

Handler for `UsbHostController.ConnectionChanged`. Called on the library's USB thread when a device is attached or detached; the devices already plugged in at `UsbHostController.Enable` time are reported too.

```python
UsbConnectionChangedEventHandler = Callable[[UsbHostController, UsbDeviceConnectionEventArgs], None]
```
