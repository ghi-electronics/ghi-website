<h1 className="api-package-heading">GHIElectronics.Endpoint.Devices.Rtc</h1>

The RTC driver for Endpoint.

## Classes

| Class | Summary |
|---|---|
| [RtcController](./RtcController.mdx) | The board's real-time clock, for .NET IoT's `RtcBase` (`Iot.Device.Rtc`). It counts UTC: at boot, the system time is set from it. `RtcController.IsValid` and `RtcController.SetChargeMode` are the same as TinyCLR's. |
