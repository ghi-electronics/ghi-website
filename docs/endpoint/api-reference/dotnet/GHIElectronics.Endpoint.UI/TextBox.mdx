## Properties

### Placeholder

```csharp
public string Placeholder { get; set; }
```

Hint text shown when `TextBox.Text` is empty. `null` is treated as empty. Getter returns the last value set.

**Returns** `string`

### Text


Current text content. Reads back live from LVGL (up to 255 UTF-8 bytes).

**Returns** `string`
