# MessageBox Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

Modal dialog with title, body text, and footer buttons. Add buttons with `MessageBox.AddButton`; each returns a handle whose Clicked event you subscribe to. Call `MessageBox.Hide` to dismiss.
