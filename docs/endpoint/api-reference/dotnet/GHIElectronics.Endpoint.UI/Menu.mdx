# Menu Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

Horizontal menu bar. `Menu.AddItem` returns a leaf-item handle; `Menu.AddDropdown` returns a dropdown handle whose entries are listed on click.

```csharp
public class Menu : Widget
```

## Constructors

### Menu(Widget parent)

```csharp
public Menu(Widget parent)
```

Create a menu bar inside `parent`.

| Parameter | Type | Description |
|---|---|---|
| `parent` | `Widget` | Containing widget. |


## Methods

### AddDropdown(string header, string[] subItems, int itemWidth)

```csharp
public MenuItem AddDropdown(string header, string[] subItems, int itemWidth)
```

Append a dropdown menu item that opens a sub-list when tapped.

| Parameter | Type | Description |
|---|---|---|
| `header` | `string` | Button text shown on the bar. |
| `subItems` | `string[]` | Sub-item strings; `null` is treated as empty. |
| `itemWidth` | `int` | Fixed width in pixels; `0` fits the text. |

**Returns** `MenuItem`: Handle for subscribing to `MenuItem.ValueChanged` and reading `MenuItem.Selected`.

**Returns** `MenuItem`: Handle for subscribing to `MenuItem.Clicked`.
