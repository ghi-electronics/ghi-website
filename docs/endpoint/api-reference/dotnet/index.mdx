# .NET API Reference

Endpoint on **.NET**: standard `System.Device.*` and .NET IoT APIs, plus the libraries below for hardware features .NET does not cover.

## Standard .NET

Endpoint's device libraries build on these standard Microsoft APIs. Code written against them on any platform ports to Endpoint unchanged.

| Microsoft .NET API | Description |
|---|---|
| [System.Device.Gpio](https://learn.microsoft.com/en-gb/dotnet/api/system.device.gpio?view=iot-dotnet-latest) | Digital inputs and outputs: pin modes, read, write, interrupts. |
| [System.Device.I2c](https://learn.microsoft.com/en-gb/dotnet/api/system.device.i2c?view=iot-dotnet-latest) | I2C bus master: read and write to devices by address. |
| [System.Device.Spi](https://learn.microsoft.com/en-gb/dotnet/api/system.device.spi?view=iot-dotnet-latest) | SPI bus master: full-duplex transfers with configurable clock and mode. |
| [System.Device.Pwm](https://learn.microsoft.com/en-gb/dotnet/api/system.device.pwm?view=iot-dotnet-latest) | PWM channels: configurable frequency and duty cycle. |
| [System.Device.Analog](https://learn.microsoft.com/en-gb/dotnet/api/system.device.analog?view=iot-dotnet-latest) | Analog inputs (ADC): read voltages from analog pins. |
| [System.IO.Ports](https://learn.microsoft.com/en-gb/dotnet/api/system.io.ports) | Serial ports (UART): the standard `SerialPort` class. |
