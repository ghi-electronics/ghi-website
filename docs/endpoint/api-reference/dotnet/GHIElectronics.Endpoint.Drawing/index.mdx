<h1 className="api-package-heading">GHIElectronics.Endpoint.Drawing</h1>

Off-screen 2D drawing primitives for Endpoint: Canvas, Color, Font, Image, PixelFormat. Pure pixel drawing independent of the LVGL-backed UI widget library. Hand the Canvas buffer to any display, SPI/I2C device, or file.

## Classes

| Class | Summary |
|---|---|
| [Canvas](./Canvas.mdx) | A pixel buffer plus the primitives to draw into it. Pick the size and `PixelFormat` at `Create` time; when done, hand `Buffer` to whichever device accepts bytes: `DisplayController.Flush`, `SpiDevice.Write`, `I2cDevice.Write`, a file, anywhere. |
| [DisplayControllerExtensions](./DisplayControllerExtensions.mdx) | Shortcut extensions so a `Canvas` can be handed to a `DisplayController` in one call without the caller spelling out the (Buffer, PixelFormat) tuple. |
| [Font](./Font.mdx) | A TrueType / OpenType font loaded from raw file bytes. Pass to `Canvas.DrawText` to render strings at any pixel size. |
| [Image](./Image.mdx) | A decoded image, ready to blit into a `Canvas`. Decoding (JPEG / PNG / BMP / GIF / TGA) happens once at `Load`; `Canvas.DrawImage` then blits + converts to the target `PixelFormat` on the fly. |

## Structs

| Struct | Summary |
|---|---|
| [Color](./Color.mdx) | A 32-bit color with 8 bits each of alpha, red, green, blue. `Canvas` maps it to its `PixelFormat` at draw time. |

## Enums
