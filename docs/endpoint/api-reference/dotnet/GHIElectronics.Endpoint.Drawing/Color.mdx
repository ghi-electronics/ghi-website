# Color Struct

**Package:** `GHIElectronics.Endpoint.Drawing`<br/>**Namespace:** `GHIElectronics.Endpoint.Drawing`

A 32-bit color with 8 bits each of alpha, red, green, blue. `Canvas` maps it to its `PixelFormat` at draw time: Monochrome treats non-zero as "lit", Rgb565 drops the low bits, Rgb888 drops alpha, Argb8888 keeps everything.

```csharp

```
