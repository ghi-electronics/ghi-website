# Canvas Class

**Package:** `GHIElectronics.Endpoint.Drawing`<br/>**Namespace:** `GHIElectronics.Endpoint.Drawing`

A pixel buffer plus the primitives to draw into it. Pick the size and `PixelFormat` at `Create` time; when done, hand `Buffer` to whichever device accepts bytes: `DisplayController.Flush`, `SpiDevice.Write`, `I2cDevice.Write`, a file, anywhere.

```csharp
public sealed class Canvas : IDisposable
```

### Example

```csharp
using var canvas = Canvas.Create(240, 320, PixelFormat.Rgb565);
canvas.Clear(Color.Black);
canvas.DrawLine(10, 10, 230, 310, Color.Red, thickness: 2);
canvas.FillCircle(120, 160, 40, Color.Blue);
canvas.DrawText("Hello Endpoint", font, 10, 30, 20, Color.White);
spi.Write(canvas.Buffer);
```

### DrawText(string text, Font font, int x, int y, int sizePx, Color color)

```csharp
public void DrawText(string text, Font font, int x, int y, int sizePx, Color color)
```

Rasterize `text` with `font` at `sizePx`, with the top-left of the text box at (`x`, `y`). Alpha-blends against whatever is already in the canvas. The font is rasterized on every call; cache into a `Canvas` and re-blit if you need high FPS. Rgb565 and Monochrome targets only.

### DrawImage(Image image, int x, int y)

```csharp
public void DrawImage(Image image, int x, int y)
```

Blit a pre-decoded `Image` into this canvas at (`x`, `y`). The image's internal pixels are converted to this canvas's `PixelFormat` on the fly. Prefer this over the raw-bytes overload in redraw loops: decoding a JPG is ~150 ms; blitting a cached `Image` is a few ms.

### DrawImage(byte[] fileBytes, int x, int y)

```csharp
public void DrawImage(byte[] fileBytes, int x, int y)
```

Decode an image file (JPEG / PNG / BMP / GIF / TGA, detected from the file's magic bytes) and blit it into this canvas at (`x`, `y`). Clips to the canvas bounds. Convenience one-shot. For repeated draws, cache the decode via `Image.Load` and call the `Image` overload.
