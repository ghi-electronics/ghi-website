# Can Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The CAN ports bundled with EPM815. Use with .NET IoT's `CanRaw` (`Iot.Device.SocketCan`, which the `GHIElectronics.Endpoint.Devices.Can` package brings). `Can.Initialize` connects the port's pins, sets its bitrate and starts it; then use `CanRaw` as usual. Each constant is the port's name for `CanRaw`, fixed by the firmware. A port that goes bus-off after too many errors restarts by itself after 100 ms.

| Parameter | Type | Description |
|---|---|---|
| `port` | `string` | Can1 or Can2 |
| `bitrate` | `int` | Bits per second, up to 1,000,000; all devices on the bus must use the same |

### UnInitialize(string port)
