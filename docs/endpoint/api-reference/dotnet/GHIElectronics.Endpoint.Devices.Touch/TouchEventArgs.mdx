# TouchEventArgs Class

Event data for `Touch.OnChangedEvent`: how the fingers changed since the last event.


## Constructors

### TouchEventArgs(TouchEventType eventType, TouchPoint[] points)

```csharp
public TouchEventArgs(TouchEventType eventType, TouchPoint[] points)
```

Builds a touch-event payload.

| Parameter | Type | Description |
|---|---|---|
| `eventType` | `TouchEventType` | What changed (pressed, moved, released). |
| `points` | `TouchPoint[]` | Every finger currently on the screen; empty when `eventType` is `TouchEventType.Released`. |
