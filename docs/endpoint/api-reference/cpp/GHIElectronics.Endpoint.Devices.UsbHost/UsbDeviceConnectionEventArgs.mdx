# UsbDeviceConnectionEventArgs Class

**Package:** `GHIElectronics.Endpoint.Devices.UsbHost`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.UsbHost`

Event data for `UsbHostController.ConnectionChanged`: one USB device attached or detached.

```cpp
class UsbDeviceConnectionEventArgs : public EventArgs {};
```

## Properties

### DeviceName

```cpp
std::string DeviceName() const;
```

What to open: "/dev/ttyUSB0", "eth1"... (see DeviceType)

**Returns** `string`

### DeviceStatus

```cpp
DeviceConnectionStatus DeviceStatus() const;
```

Whether the device was just connected or just disconnected.

**Returns** `DeviceConnectionStatus`

### Id

```cpp
uint32_t Id() const;
```

The device's number: the same for all its events, a new one when it is plugged in again

**Returns** `uint`

### Manufacturer

```cpp
std::string Manufacturer() const;
```

The device's own name for its maker ("Logitech"), empty if it has none

**Returns** `string`

### Product

```cpp
std::string Product() const;
```

The device's own name ("USB Receiver"), empty if it has none

**Returns** `string`

### ProductId

```cpp
uint16_t ProductId() const;
```

USB product id (PID) from the device descriptor.

**Returns** `ushort`

### SerialNumber

```cpp
std::string SerialNumber() const;
```

Empty if the device has none

**Returns** `string`

### Type

```cpp
DeviceType Type() const;
```

What the device gives (see `UsbHost.DeviceType`); hints what to open `UsbDeviceConnectionEventArgs.DeviceName` with.

**Returns** `DeviceType`

### VendorId

```cpp
uint16_t VendorId() const;
```

USB vendor id (VID) from the device descriptor.

**Returns** `ushort`
