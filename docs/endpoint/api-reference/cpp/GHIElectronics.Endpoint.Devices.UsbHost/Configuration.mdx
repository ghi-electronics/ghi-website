## Methods

### FillChildren(byte[] bytes, int offset)

```cpp
void FillChildren(const std::vector<uint8_t>& bytes, int32_t offset);
```

Walks a config-descriptor blob from `offset` to the end and fills `Configuration.Interfaces`, the nested endpoints, and `Configuration.AuxiliaryDescriptors`.

| Parameter | Type | Description |
|---|---|---|
| `bytes` | `byte[]` | The full configuration-descriptor blob (length = `Configuration.TotalLength`). |
| `offset` | `int` | Byte offset to start parsing children: typically `Configuration.FixedLength` when the blob starts with the configuration header. |
