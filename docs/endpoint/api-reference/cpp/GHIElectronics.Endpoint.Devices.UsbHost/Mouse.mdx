# Mouse Class

**Package:** `GHIElectronics.Endpoint.Devices.UsbHost`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.UsbHost`

Allows a usb device to be used a mouse.

```cpp
class Mouse : public BaseDevice {};
```

### Remarks

By default, the reported range for position is between 0 and 512, as on TinyCLR: set it to the screen with `SetCursorBounds`. The events come on the mouse's own thread.
