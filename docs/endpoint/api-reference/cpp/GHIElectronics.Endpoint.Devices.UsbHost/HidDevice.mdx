# HidDevice Class

**Package:** `GHIElectronics.Endpoint.Devices.UsbHost`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.UsbHost`

A HID device that is no keyboard, mouse or joystick (a sensor, a USB I/O board, a UPS...): its reports, as hidapi gives them.

```cpp
class HidDevice : public BaseDevice {};
```

### Remarks

Open it with the DeviceName of a HID device from `UsbHostController` ("/dev/hidraw0"). A report's first byte is its report ID: 0 for a device that does not number its reports.

## Constructors

### HidDevice(string deviceName)

```cpp
HidDevice(const std::string& deviceName);
```

Opens the HID device that UsbHostController reported ("/dev/hidraw0").

### Read(Span&lt;byte> buffer, int timeout)

```cpp
int32_t Read(Span<uint8_t> buffer, int32_t timeout);
```

Reads an input report (its first byte is its report ID if the device numbers its reports).

| Parameter | Type | Description |
|---|---|---|
| `buffer` | `Span<byte>` | Where the report goes. |
| `timeout` | `int` | How long to wait for one, in milliseconds (Timeout.Infinite: as long as it takes). |

**Returns** `int`: The report's length, 0 if none came in time.
