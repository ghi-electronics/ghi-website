# C/C++ API Reference

Endpoint on **C/C++**: the same libraries as .NET and Python, with identical class and method names, exposed as a C++23 header library.

## Standard

C/C++ has no standard peripheral API, so GPIO, I2C, SPI, PWM, and the rest are published by GHI with class and method names identical to .NET. The UI library embeds LVGL; for widgets and graphics features beyond what the Endpoint UI wrappers expose, the full LVGL API is available directly.

| Library | Description |
|---|---|
| [LVGL](https://docs.lvgl.io/master/) | The graphics and UI library embedded in `libendpoint`. Used directly from C/C++ when you need features beyond the Endpoint UI wrappers. |
