# Gauge Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

Radial dial with a needle. Not a standard .NET widget: the API mirrors TinyCLR's Gauge. SweepAngle is 180/270/360 degrees.

```cpp
class Gauge : public Widget {};
```

## Constructors

### Gauge(Widget parent, int width, int height)

```cpp
Gauge(const Widget& parent, int32_t width, int32_t height);
```

Create a gauge inside `parent`.

| Parameter | Type | Description |
|---|---|---|
| `parent` | `Widget` | Containing widget. |
| `width` | `int` | Width in pixels. |
| `height` | `int` | Height in pixels. |

## Properties

