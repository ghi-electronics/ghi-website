# UiTimer Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

Thread-safe periodic callback that runs on the UI thread. The `callback` fires inside `UI.Run`'s LVGL pump every `periodMs` milliseconds, so widget updates in it are safe (LVGL itself is single- threaded). Dispose cancels the timer. Create / SetPeriod / Dispose are safe from any thread; the body runs on the UI thread.

```cpp
class UiTimer : public IDisposable {};
```

## Constructors

### UiTimer(uint periodMs, Action callback)

```cpp
UiTimer(uint32_t periodMs, const Action& callback);
```

Create a periodic timer that fires `callback` on the UI thread.

| Parameter | Type | Description |
|---|---|---|
| `periodMs` | `uint` | Period in milliseconds between callbacks. |
| `callback` | `Action` | Delegate to invoke on each tick; runs on LVGL's event thread so widget updates are safe. |
