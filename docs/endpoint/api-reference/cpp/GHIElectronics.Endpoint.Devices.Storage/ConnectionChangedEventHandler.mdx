# ConnectionChangedEventHandler Delegate

**Package:** `GHIElectronics.Endpoint.Devices.Storage`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Storage`

Handler for `StorageController.ConnectionChanged`. Called on the library's storage thread when a drive is attached or detached; the drives already plugged in at `StorageController.Enable` time are reported too.

```cpp
using ConnectionChangedEventHandler = std::function<void(StorageController, DeviceConnectionEventArgs)>;
```
