# SpiController Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Chip-neutral entry point for SPI setup. Call once before using `Spi.SpiDevice`: it brings up the bus and muxes its pins.

```cpp
class SpiController {};
```

## Methods

### Initialize(int bus, int bufferSize)

```cpp
static void Initialize(int32_t bus, int32_t bufferSize);
```

Connects the bus's SCK/MISO/MOSI pins. On EPM815, also sizes the kernel transfer buffer; on EPN256/EPN128 `bufferSize` is accepted for signature parity and otherwise ignored (the Nuvoton driver uses a fixed DMA buffer).

### UnInitialize(int bus)

```cpp
static void UnInitialize(int32_t bus);
```

Releases the bus's pins back to free GPIO.
