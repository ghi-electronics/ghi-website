# Gpio Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

GPIO pins and the register-level pin configuration (mode, alternate function, pull, speed, output type) for EPM815. Most applications should use the standard `Gpio.GpioController` through `Gpio.Driver`; the enums and setters here are for the low-level peripheral libraries in this package.

```cpp
class Gpio {};
```
