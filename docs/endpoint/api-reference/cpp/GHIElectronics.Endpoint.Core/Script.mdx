# Script Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Runs an external program and collects what it prints. Used internally by the Endpoint libraries where a direct API is not yet available; prefer the direct API where one exists.

```cpp
class Script {};
```

## Constructors

### Script(string filename, string workingdir, string arguments)

```cpp
Script(const std::string& filename, const std::string& workingdir, const std::string& arguments);
```

Prepares to run `filename` with the given arguments and working directory.

| Parameter | Type | Description |
|---|---|---|
| `filename` | `string` | Path to the program, or a name that `PATH` resolves. |
| `workingdir` | `string` | Working directory for the program; empty for the current one. |
| `arguments` | `string` | Command-line arguments as a single string, split by the shell convention. |
