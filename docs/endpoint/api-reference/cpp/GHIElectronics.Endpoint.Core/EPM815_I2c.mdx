# I2c Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The I2C buses bundled with EPM815. Use with .NET's `System.Device.I2c`. `I2c.Initialize` connects the bus's pins and sets its speed; then use `I2cDevice` as usual. Each constant is the bus number for `I2cConnectionSettings` (`/dev/i2c-N`), fixed by the firmware.

```cpp
class I2c {};
```

## Methods

### GetFrequency(int bus)

```cpp
static int32_t GetFrequency(int32_t bus);
```

The bus speed in use, in Hz

**Returns** `int`

### Initialize(int bus, int frequency)

```cpp
static void Initialize(int32_t bus, int32_t frequency);
```

Connects the bus's pins (open drain, with the internal pull-ups on for boards without their own) and sets its speed, until the next boot

| Parameter | Type | Description |
|---|---|---|
| `bus` | `int` | I2c1, I2c4, I2c5 or I2c6 |
| `frequency` | `int` | The bus speed in Hz, from 10 kHz to 1 MHz |

### UnInitialize(int bus)

```cpp
static void UnInitialize(int32_t bus);
```

Gives the bus's pins back, as they were before Initialize
