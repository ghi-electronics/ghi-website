# EPDomino24 Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

EP-Domino24 Rev B: a board variant of the EPM815 module with a 40-pin header, two mikroBUS sockets and a handful of onboard components. Same chip and firmware as `Core.EPM815`; this class is a thin re-naming layer that lists only the peripherals and pins actually bonded on the board, so application code reads what a user looking at the EP-Domino24 silkscreen expects.

```cpp
class EPDomino24 {};
```
