# Color Struct

**Header:** `endpoint/Drawing.h`<br/>**Namespace:** `GHIElectronics::Endpoint::Drawing`

A 32-bit color with 8 bits each of alpha, red, green, blue. `Canvas` maps it to its `PixelFormat` at draw time.

```cpp
struct Color {
    uint8_t R = 0;
    uint8_t G = 0;
    uint8_t B = 0;
    uint8_t A = 0xFF;
};
```

## Constructors

### Color()

```cpp
constexpr Color();
```

Fully opaque black.

### Color(uint8_t r, uint8_t g, uint8_t b)

```cpp
constexpr Color(uint8_t r, uint8_t g, uint8_t b);
```

Opaque color from R/G/B.

### Color(uint8_t r, uint8_t g, uint8_t b, uint8_t a)

```cpp
constexpr Color(uint8_t r, uint8_t g, uint8_t b, uint8_t a);
```

Color from R/G/B and alpha.

## Methods

### FromArgb(uint32_t argb)

```cpp

```

### FromRgb(uint32_t rgb)

```cpp
static constexpr Color FromRgb(uint32_t rgb);
```

Color from a 0xRRGGBB value, opaque.
