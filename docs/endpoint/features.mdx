# Features

Endpoint runs full .NET Core, Python, and C++ on embedded hardware. The pages below cover the hardware and system capabilities the platform adds, from pin-level I/O and communication buses to networking, cloud integration, storage, and displays.

Click any feature to jump to its reference page.

## Hardware I/O

The basics every embedded project starts with: direct pin control, analog input and output, PWM, and timing-critical signals.

- [GPIO](feature/gpio.mdx) — digital input and output on any pin
- [PWM](feature/pwm.mdx) — pulse-width modulation for motors, LEDs, and audio
- [Analog In](feature/analog-in.mdx) — read voltages from sensors and analog sources
- [Analog Out](feature/analog-out.mdx) — produce analog voltages via DAC
- [Signal Control](feature/signal-control.mdx) — generate and measure precise digital signals

## Communication Buses

Talk to peripheral chips, sensors, displays, and external systems.

- [SPI](feature/spi.mdx) — high-speed serial peripheral interface
- [I2C](feature/i2c.mdx) — two-wire interface for sensors and small peripherals
- [UART](feature/uart.mdx) — serial communication with external hardware
- [USB](feature/usb.mdx) — USB devices and communication
- [CAN](feature/can.mdx) — controller area network for automotive and industrial use

## Networking

Connect your application to networks and nearby devices.

- [Networking](feature/networking.mdx) — network configuration, sockets, and cloud connectivity
- [Bluetooth](feature/bluetooth.mdx) — Bluetooth through the BlueZ stack

## Cloud

Connect to the major cloud platforms over MQTT.

- [Microsoft Azure](feature/azure.mdx) — Microsoft Azure IoT Hub
- [Amazon Web Services](feature/aws.mdx) — Amazon Web Services IoT

## Storage

Persist data on SD cards, USB drives, or in a real SQL database.

- [File System](feature/file-system.mdx) — read and write files on USB and SD storage
- [SQLite Database](feature/databases.mdx) — embedded SQL database

## Display & Multimedia

Drive screens, capture images, and build rich user interfaces.

- [Displays](feature/displays.mdx) — parallel TFT and serial displays
- [Touch Screen](feature/touch-screen.mdx) — capacitive touch input
- [User Interface](feature/ui.mdx) — a UI library inspired by Windows Presentation Foundation
- [Graphics](feature/graphics.mdx) — drawing with SkiaSharp
- [Camera](feature/camera.mdx) — digital cameras through USB or the parallel interface
- [MJPEG Video](feature/mjpeg-video.mdx) — video as a chain of JPEG images

## System Services

Keep a device running, on time, and up to date.

- [In-Field Update](feature/in-field-update.mdx) — update the system from SD or USB memory
- [Power Management](feature/power-management.mdx) — power modes and shutdown
- [Watchdog](feature/watchdog-timer.mdx) — reset the system if it locks up
- [Real Time Clock](feature/real-time-clock.mdx) — keep time while the system is powered off
