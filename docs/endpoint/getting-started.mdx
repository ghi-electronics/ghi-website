# Getting Started with Endpoint

Endpoint runs **full .NET, Python, and C/C++** on a circuit. All three share one set of APIs, so what you learn in one language travels with you. You debug them over a USB cable, with no keys, passwords, or IP addresses.

:::note[Evaluation hardware]
[Endpoint Domino24](hardware.mdx) is the evaluation board we built for Endpoint. We have not released SoMs or dev boards yet, because we are still shaping what the commercial product should be. Tell us what you need on the [forum](https://forums.ghielectronics.com/): what form factor, which peripherals, and whether wireless is a requirement.
:::

## Languages and tools

| Language | Version | VS Code | Visual Studio |
|---|---|---|---|
| **C#** | .NET 11 | Yes | Yes |
| **Python** | Python 3.14 | Yes | No |
| **C and C++** | C23 and C++23, with no toolchain to install | Yes | No |

## What you'll need

- **[Endpoint Domino24](hardware.mdx)**
- A **USB-C cable**
- A **microSD card** of at least 4 GB
- **VS Code** for any language, or **Visual Studio** for .NET

## Step 1: Prepare the board

1. Download the latest Endpoint OS image from the [Downloads](downloads.mdx) page.
2. Write the image to the microSD card with a disk imaging tool such as balenaEtcher.
3. Insert the card into Domino24 and connect it to your PC with the USB-C cable.
4. Wait for the **USER LED** to light, which shows the board has finished booting.

## Step 2: Install the extension

<Tabs groupId="ide">
<TabItem value="vs" label="Visual Studio" default>

Visual Studio supports **.NET (C#)**.

1. **Visual Studio 2026** (Community, Professional or Enterprise). VS 2022 17.9+ also works.
2. The matching **.NET SDK** installed and on PATH ([download](https://dotnet.microsoft.com/download)).
3. The **Endpoint Debugger** extension. Install the latest `endpoint_vs_debugger-win32-x64-*.vsix` from the [Downloads](downloads.mdx) page.

</TabItem>
<TabItem value="vscode" label="Visual Studio Code">

Visual Studio Code supports **.NET (C#)**, **Python**, and **C/C++**, all three languages from the same extension.

1. **Visual Studio Code**.
2. The **Endpoint Debugger** extension. Install the latest `endpoint_vsc_debugger-win32-x64-*.vsix` from the [Downloads](downloads.mdx) page.
3. For each language you want to use:
   - **.NET (C#)**: the matching [.NET SDK](https://dotnet.microsoft.com/download) and the [C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp) extension.
   - **Python**: [Python](https://www.python.org/downloads/) and the [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) + [Python Debugger](https://marketplace.visualstudio.com/items?itemName=ms-python.debugpy) extensions.
   - **C/C++**: the [C/C++](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools) extension.

</TabItem>
</Tabs>

## Step 3: Create a project

<Tabs groupId="ide">
<TabItem value="vs" label="Visual Studio" default>

1. **File > New > Project...** → search *"Endpoint"* → choose **Endpoint App (C#)**. Give it a name and location.

   ![Endpoint App (C#) template in the Visual Studio new-project dialog](/img/docs/endpoint/vs-new-project-template.png)

</TabItem>
<TabItem value="vscode" label="Visual Studio Code">

1. Plug the board in with USB. The status bar at the bottom of VS Code shows **Endpoint** when the board is detected:

   ![Endpoint shown in the VS Code status bar](/img/docs/endpoint/vscode-endpoint-statusbar.png)

2. **Ctrl+Shift+P** → **Endpoint: New Project...** → pick a language (**.NET**, **Python** or **C/C++**), a name and a folder. VS Code opens the new project.

   ![New Endpoint Project language picker in VS Code](/img/docs/endpoint/vscode-new-project-language.png)

</TabItem>
</Tabs>

## Step 4: Deploy and run

<Tabs groupId="ide">
<TabItem value="vs" label="Visual Studio" default>

Plug the board in with USB and press **F5**. Visual Studio builds the project, copies it to the board, and starts the debugger. Breakpoints, step, locals and watch work as usual.

**Project settings** live under the project's **Endpoint** property page:

![Endpoint project settings in Visual Studio](/img/docs/endpoint/vs-endpoint-settings.png)

- **Transport**: how Visual Studio talks to the board. USB today.
- **Device**: **Endpoint** runs the program on the board; **Desktop** runs it locally on the PC for quick checks.
- **Firmware**: check for updates, erase the application that is set to run at boot.

**Run at boot:** press **Ctrl+F5** instead of F5. The project is built in AOT mode and marked to start automatically after power-on. A C# blink app goes from power-on to running in less than three seconds.

</TabItem>
<TabItem value="vscode" label="Visual Studio Code">

Press **F5**. The extension builds the project, copies it to the board, and starts the debugger. If something is wrong (board not connected, in use by another program, not answering), F5 stops with a clear message instead of running.

**Run at boot:** press **Ctrl+F5** instead of F5. The project is built in AOT mode and marked to start automatically after power-on, same as in Visual Studio.

</TabItem>
</Tabs>

:::tip
Only one program at a time holds the USB connection. Close the Endpoint Config tool before using F5 in Visual Studio or VS Code, and vice versa.
:::
