# Getting Started with Endpoint

Endpoint runs **full .NET Core, Python, and C++** on a circuit. All three share one set of APIs, so what you learn in one language travels with you. You debug them over a USB cable, with no keys, passwords, or IP addresses.

:::note[Evaluation hardware]
[Endpoint Domino](hardware.mdx) is the evaluation board we built for Endpoint. We have not released SoMs or dev boards yet, because we are still shaping what the commercial product should be. Tell us what you need on the [forum](https://forums.ghielectronics.com/): what form factor, which peripherals, and whether wireless is a requirement.
:::

## Languages and tools

| Language | Version | VS Code | Visual Studio |
|---|---|---|---|
| **C#** | .NET 11 | Yes | Yes |
| **Python** | Python 3.14 | Yes | No |
| **C and C++** | C23 and C++23, with no toolchain to install | Yes | No |

## What you'll need

- **[Endpoint Domino](hardware.mdx)**
- A **USB-C cable**
- A **microSD card** of at least 4 GB
- **VS Code** for any language, or **Visual Studio** for .NET

## Step 1 — Prepare the board

1. Download the latest Endpoint OS image from the [Downloads](downloads.mdx) page.
2. Write the image to the microSD card with a disk imaging tool such as balenaEtcher.
3. Insert the card into Domino and connect it to your PC with the USB-C cable.
4. Wait for the **USER LED** to light, which shows the board has finished booting.

## Step 4 — Run it

Plug in the USB cable, pick your board from the list, and press **F5**. There are no keys, passwords, or IP addresses to set up.

A C# blink application goes from power on to running in less than three seconds.
