Endpoint provides full networking through .NET's standard `System.Net`
stack (sockets, HTTP/HTTPS, WebSockets, TLS). The Endpoint-specific
`GHIElectronics.Endpoint.Devices.Network` package is only for bringing the
network interface up and configuring it. The same package is shipped for
Python and C/C++, with the same class and method names.

Two interface types are supported:

- **Ethernet**: the board's built-in Ethernet, or any USB Ethernet adapter.
- **Wi-Fi**: a built-in Wi-Fi module, or a USB Wi-Fi dongle.

Settings persist in `/config/network.json`. Nothing starts automatically at
boot; the application calls `Enable()` on the interfaces it wants up.

## Wi-Fi

<Tabs groupId="lang">
<TabItem value="dotnet" label=".NET" default>

```csharp
using GHIElectronics.Endpoint.Devices.Network;

var wifi = NetworkController.FromType(NetworkType.Wifi);

var settings = new WiFiNetworkInterfaceSettings {
    Ssid = "MyNetwork",
    Password = "secret123",
    Security = WiFiSecurityType.Wpa2,
    IsDhcpEnabled = true,
};

wifi.SetInterfaceSettings(settings);   // saves to /config/network.json
wifi.Enable();                          // brings the interface up, runs DHCP

Console.WriteLine($"Connected: {wifi.IsConnected}");
Console.WriteLine($"Interface: {wifi.Name}");

// Standard .NET info is also available
var nic = wifi.NetworkInterface;
if (nic != null) {
    foreach (var ip in nic.GetIPProperties().UnicastAddresses)
        Console.WriteLine(ip.Address);
}
```

</TabItem>
<TabItem value="python" label="Python">

```python
import socket
from GHIElectronics.Endpoint.Devices.Network import (
    NetworkController, NetworkType,
    WiFiNetworkInterfaceSettings, WiFiSecurityType,
)

wifi = NetworkController.FromType(NetworkType.Wifi)

settings = WiFiNetworkInterfaceSettings()
settings.Ssid = "MyNetwork"
settings.Password = "secret123"
settings.Security = WiFiSecurityType.Wpa2
settings.IsDhcpEnabled = True

wifi.SetInterfaceSettings(settings)    # saves to /config/network.json
wifi.Enable()                           # brings the interface up, runs DHCP

print(f"Connected: {wifi.IsConnected}")
print(f"Interface: {wifi.Name}")

# Standard Python info is also available via the socket module
if wifi.Name:
    print(socket.gethostbyname(socket.gethostname()))
```

</TabItem>

## Using the network

Once an interface is enabled, use the standard networking surface of your
language (HTTP, sockets, WebSockets, TLS) exactly as you would on a PC:

<Tabs groupId="lang">
<TabItem value="dotnet" label=".NET" default>

```csharp
using var http = new HttpClient();
var json = await http.GetStringAsync("https://api.example.com/status");
Console.WriteLine(json);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import urllib.request

with urllib.request.urlopen("https://api.example.com/status") as resp:
    print(resp.read().decode())
```

</TabItem>
<TabItem value="cpp" label="C/C++">

```cpp
// The Endpoint firmware ships libcurl. Link with -lcurl.
#include <cstdio>
#include <curl/curl.h>

static size_t WriteCallback(void* data, size_t size, size_t count, void*) {
    std::fwrite(data, size, count, stdout);
    return size * count;
}

CURL* curl = curl_easy_init();
curl_easy_setopt(curl, CURLOPT_URL, "https://api.example.com/status");
curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, WriteCallback);
curl_easy_perform(curl);
curl_easy_cleanup(curl);
```

## TLS certificates

HTTPS clients on Endpoint trust the public CA bundle out of the box, same as any desktop. If your server uses a **self-signed certificate** or a **private CA**, ship the CA certificate (PEM file) with your app and tell the HTTP client to trust it.

<Tabs groupId="lang">
<TabItem value="dotnet" label=".NET (C#)" default>

```csharp
using System.IO;
using System.Net.Http;
using System.Security.Cryptography.X509Certificates;

var ca = new X509Certificate2(Path.Combine(AppContext.BaseDirectory, "ca.crt"));

var handler = new HttpClientHandler {
    ServerCertificateCustomValidationCallback = (msg, chain, errors) => {
        chain.ChainPolicy.CustomTrustStore.Add(ca);
        chain.ChainPolicy.TrustMode = X509ChainTrustMode.CustomRootTrust;
        return chain.Build(chain.ChainElements[0].Certificate);
    },
};

using var http = new HttpClient(handler);
var body = await http.GetStringAsync("https://my-server.local/");
```

For mutual TLS (client certificate too), add `handler.ClientCertificates.Add(new X509Certificate2("client.pfx", password));`.

</TabItem>
<TabItem value="python" label="Python">

```python
import requests
from pathlib import Path

cert = str(Path(__file__).parent / "ca.crt")
r = requests.get("https://my-server.local/", verify=cert)
print(r.text)
```

For mutual TLS, pass the client cert + key: `requests.get(url, verify=ca, cert=(client_cert, client_key))`.

Install `requests` the usual way: `pip install requests`.

</TabItem>
<TabItem value="cpp" label="C/C++">

The firmware ships with libcurl + its OpenSSL backend. Drop the curl headers into your project (download from [curl.se](https://curl.se/download.html) or copy from a Linux `libcurl4-openssl-dev` package), then:

```cpp
#include <curl/curl.h>
#include <filesystem>

auto cert = std::filesystem::canonical("/proc/self/exe").parent_path() / "ca.crt";

CURL* curl = curl_easy_init();
curl_easy_setopt(curl, CURLOPT_URL, "https://my-server.local/");
curl_easy_setopt(curl, CURLOPT_CAINFO, cert.c_str());
curl_easy_perform(curl);
curl_easy_cleanup(curl);
```

For mutual TLS, add `curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.crt")` and `CURLOPT_SSLKEY` for the private key.

</TabItem>
