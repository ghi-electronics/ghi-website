## IDE extensions

The Endpoint Debugger extension for your IDE. The extensions also bundle
the project templates and, during preview, the Endpoint libraries
themselves. They are extracted into a new project the first time you
create one.

## Libraries

The Endpoint libraries are still in preview, so they are not yet
published to the public package registries (**NuGet.org** for .NET and
**PyPI** for Python). The current set for all three languages (.NET,
Python, C/C++) is bundled inside both IDE extensions and is extracted
into your workspace the first time you create a new Endpoint project,
so no separate download is required.
