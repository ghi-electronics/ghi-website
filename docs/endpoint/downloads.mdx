## Libraries

The Endpoint libraries are on the public package registries. New projects
created from the IDE templates reference them already, so no separate
download is required.

Language | Registry | Package
--- | --- | ---
.NET | [NuGet.org](https://www.nuget.org/packages/GHIElectronics.Endpoint.Core/) | `GHIElectronics.Endpoint.Core` (and `Devices.*`, `UI`)
Python | [PyPI](https://pypi.org/project/GHIElectronics.Endpoint.Core/) | `GHIElectronics.Endpoint.Core` (and `Devices.*`, `UI`)
C/C++ | bundled in the VS Code extension | `endpoint/` folder with `libendpoint.a` + headers
