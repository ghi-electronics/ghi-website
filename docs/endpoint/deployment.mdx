title: Deploy and Run
description: Debug Endpoint applications over USB with F5, compile for run at boot with Ctrl+F5, and install Python packages onto the board over USB.
---

## Debug over USB

Plug in the USB cable, pick your board from the list, and press **F5**. There's no SSH, and there are no keys, passwords, or IP addresses. This works the same for all three languages.

VS Code supports .NET, Python, and C/C++. Visual Studio supports .NET.

## Run at boot

Press **Ctrl+F5** to compile your application in AOT mode and set it to run at boot.

A C# blink application goes from power on to running in less than three seconds.

## Install Python packages

Install Python packages onto the board from VS Code, over USB, from your PC. The board doesn't need an internet connection.
