Installs an init.d entry (`/etc/init.d/S29custom`) that starts the given deployed .NET application at boot. The application is expected at `/root/.epdata/{applicationName}/{applicationName}.dll`.

| Parameter | Type | Description |
|---|---|---|
| `applicationName` | `string` | Folder and assembly name (without `.dll`) under `/root/.epdata/`. |
