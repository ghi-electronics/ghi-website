# DeviceInformation Class

**Package:** `GHIElectronics.Endpoint.Native`<br/>**Namespace:** `GHIElectronics.Endpoint.Native`

Board identity, firmware version, and boot/auto-run configuration helpers.

```csharp
public static class DeviceInformation
```

## Properties

### Version

```csharp
public static string Version { get; }
```

Firmware version string as reported by `get_version.sh`, with any trailing newline stripped.

**Returns** `string`

## Methods

### DisableAutoRun()

```csharp
public static void DisableAutoRun()
```

Removes the auto-run init.d entry installed by `DeviceInformation.EnableAutoRun`.

### DisableSSH()

```csharp
public static void DisableSSH()
```

Permanently removes the SSH (`S50dropbear`) and USB gadget (`S30usbgadget`) init.d entries, so neither service starts at the next boot. Intended for release builds only.

### EnableAutoRun(string applicationName)

```csharp
public static void EnableAutoRun(string applicationName)
```

Installs an init.d entry (`/etc/init.d/S29custom`) that starts the given deployed .NET application at boot. The application is expected at `/root/.epdata/{applicationName}/{applicationName}.dll`.

| Parameter | Type | Description |
|---|---|---|
| `applicationName` | `string` | Folder and assembly name (without `.dll`) under `/root/.epdata/`. |

### SdBoot()

```csharp
public static bool SdBoot()
```

Returns `true` when the board booted from the SD card, `false` when it booted from the on-board eMMC.

**Returns** `bool`
