Arms a GPIO wake-up input so a transition on it brings the system out of standby.

| Parameter | Type | Description |
|---|---|---|
| `wakeupPin` | `WakeupPin` | The pin to monitor. See `Power.WakeupPin`. |
| `edge` | `PinEventTypes` | `PinEventTypes.Rising` wakes on a high level with pull-down enabled; `PinEventTypes.Falling` wakes on a low level with pull-up enabled. `PinEventTypes.None` is not supported and throws. |

### EnableWakeup(DateTime dtWakeup, WakeupPin wakeupPin, PinEventTypes edge)


Arms an RTC alarm and, optionally, a GPIO wake-up input so either event brings the system out of standby. The RTC alarm is scheduled via `rtcwake`; pass `DateTime.MaxValue` to skip the RTC and arm only the pin.

| Parameter | Type | Description |
|---|---|---|
| `dtWakeup` | `DateTime` | Absolute time at which to wake. Use `DateTime.MaxValue` for no RTC alarm. |
| `wakeupPin` | `WakeupPin` | Optional wake-up pin; defaults to `WakeupPin.None` (no pin wake). |
| `edge` | `PinEventTypes` | Active edge for the pin wake. Defaults to `PinEventTypes.Rising`. `PinEventTypes.None` is not supported and throws. |
