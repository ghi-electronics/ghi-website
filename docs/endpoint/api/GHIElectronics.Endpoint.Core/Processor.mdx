# Processor Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Identifies the processor the firmware is running on. Libraries that need board-specific behaviour read `Processor.Name` and compare against the processor-id constants exposed here.
