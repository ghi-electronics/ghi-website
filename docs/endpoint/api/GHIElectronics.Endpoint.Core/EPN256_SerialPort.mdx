# SerialPort Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The user-facing serial ports (UARTs) bundled with EPN256, for `System.IO.Ports.SerialPort`. The console UART is reserved for the kernel and not exposed here. The three ports below have stable names, so `SerialPort.Uart11` is always `/dev/ttyS11`. `SerialPort.Initialize` brings up the UART, claiming its TX / RX pins; `SerialPort.UnInitialize` returns them to free GPIO. Both are safe to call multiple times; the first `SerialPort.Initialize` does the work and the matching `SerialPort.UnInitialize` undoes it.

| Parameter | Type | Description |
|---|---|---|
| `device` | `string` | One of `SerialPort.Uart11`, `SerialPort.Uart12`, `SerialPort.Uart14`. |
