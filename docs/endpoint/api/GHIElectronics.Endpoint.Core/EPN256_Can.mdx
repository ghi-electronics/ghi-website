# Can Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

CAN interfaces bundled with EPN256. `Can.Initialize` claims a port's pins and starts it; `Can.UnInitialize` releases them. Interface names are stable, so `Can.Can0` is always `can0`.

