# Adc Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The ADC channels bundled with EPN256. Call `Adc.ReadMillivolts` on `Adc.Eadc0` and the channel index to read a channel. Channels 0 - 3 of `Adc.Eadc0` drive the resistive touch screen on the reference panel; stay off those unless the touch subnode has been removed.
