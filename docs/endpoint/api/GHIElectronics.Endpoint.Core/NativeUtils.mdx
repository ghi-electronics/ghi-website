# NativeUtils Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Low-level helpers backed by the native `nativeutils.so` library: a CPU wait-for-interrupt and a hardware-assisted JPEG to RGB888 decoder.

Decodes a JPEG image to packed 24-bit RGB888 pixels. Uses the hardware JPEG decoder when the chip has one; otherwise a software decoder in the native library.

| Parameter | Type | Description |
|---|---|---|
| `src` | `byte[]` | JPEG-encoded bytes. |
| `size` | `int` | Number of valid bytes in `src`. |
| `dest` | `byte[]` | Destination buffer, large enough for width * height * 3 bytes. |
