# Pin Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The EPN256's pins (ports A to N, 16 pins per port).

```csharp
public static class Pin
```

### Remarks

Each constant is packed as `port * 16 + line`. The letter after P is the `Gpio.Port` and the digits 0..15 are the pin within that port.
