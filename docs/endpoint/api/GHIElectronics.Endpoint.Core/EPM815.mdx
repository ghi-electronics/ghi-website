# EPM815 Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The EPM815 module: its pin names and the pin setup the other libraries use. Pin numbers are port * 16 + pin, with port Z after port I.

public static class EPM815
