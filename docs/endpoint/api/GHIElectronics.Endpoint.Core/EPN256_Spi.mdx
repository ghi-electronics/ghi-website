# Spi Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

SPI controllers bundled with EPN256. At boot nothing probes, so pins stay free GPIO; `Spi.Initialize` brings up the bus and `/dev/spidev<N>.0` appears for userspace. Pin assignments are chosen so none collide with the EPN256 bundled hardware, the console UART, or the resistive touch pins.


Brings up the SPI controller and userspace glue so `/dev/spidev{bus}.0` appears for the chosen bus. The bus's SS / CLK / MOSI / MISO pins are muxed as part of the probe.

| Parameter | Type | Description |
|---|---|---|
| `bus` | `int` | `Spi.Spi0`, `Spi.Spi1`, `Spi.Spi2` or `Spi.Spi3`. |
