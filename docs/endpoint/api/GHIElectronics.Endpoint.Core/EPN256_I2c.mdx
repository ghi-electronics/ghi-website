# I2c Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

The I2C buses bundled with EPN256. Use with .NET's `System.Device.I2c`. `I2c.Initialize` brings up the bus and muxes its pins; `I2c.UnInitialize` tears it down so the pins return to free GPIO. The buses are kept unprobed until a userspace library needs them (pay-for-use rule). Each constant is the bus number for `I2cConnectionSettings` (`/dev/i2c-N`).

Brings up the I2C controller so `/dev/i2c-{bus}` appears and the bus's pins are muxed. May be called more than once for the same bus; the same number of `I2c.UnInitialize` calls then releases it.

| Parameter | Type | Description |
|---|---|---|
| `bus` | `int` | I2c1, I2c2, I2c3, I2c4 or I2c5. |
| `frequency` | `int` | The bus speed in Hz, from 10 kHz to 1 MHz. A non-default value is accepted but not yet applied; the controller currently runs at its configured default speed. |

Reverse of `I2c.Initialize`. When the last outstanding `I2c.Initialize` for any bus is matched, the I2C driver is unloaded, which releases the pin mux for every bus and returns their pins to free GPIO.
