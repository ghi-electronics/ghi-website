# Gpio Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

GPIO pins and the module-level pin numbering scheme. Pin numbers are packed as `port * 16 + line`, where port is a `Gpio.Port` value (A..N) and line is 0..15. Most applications should use the standard `Gpio.GpioController` through `Gpio.Driver` rather than the module-level helpers.
