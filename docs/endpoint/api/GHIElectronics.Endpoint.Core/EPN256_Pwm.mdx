# Pwm Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

PWM channels bundled with EPN256, for `System.Device.Pwm`. The PWM controller stays unprobed and its pins stay free GPIO until `Pwm.Initialize` loads its driver. Reverse with `Pwm.UnInitialize`. The `EPWM_` number is the instance number; the sysfs `pwmchipN` is probe-order and is resolved at `Pwm.Initialize` time, so application code never has to deal with it.
