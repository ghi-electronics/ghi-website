# NativeRpmsgHelper Class

**Package:** `GHIElectronics.Endpoint.Core`<br/>**Namespace:** `GHIElectronics.Endpoint.Core`

Low-level helper used by other libraries to talk to the firmware's hardware timing helper. Data is exchanged as 32-bit words in fixed-size blocks of `NativeRpmsgHelper.BlockSize` words. Most applications never call this directly; `Core.EPM815`-based classes such as `DigitalSignalController` use it internally.

## Methods

### Acquire()

```csharp
public static int Acquire()
```

Opens the helper endpoint and reserves it for this process. Call before `NativeRpmsgHelper.Send` or `NativeRpmsgHelper.StartReceiving`.

**Returns** `int` — Zero on success, a negative error code otherwise.

### Ping()

```csharp
public static int Ping()
```

Sends a ping message to the remote core and waits for a reply, as a quick link check.

**Returns** `int` — Zero when the remote responds, a negative error code otherwise.

### Release()

```csharp
public static int Release()
```

Releases the helper endpoint previously opened by `NativeRpmsgHelper.Acquire`.

**Returns** `int` — Zero on success, a negative error code otherwise.

### Send(uint[] data, int offset, int count)

```csharp
public static int Send(uint[] data, int offset, int count)
```

Sends `count` 32-bit words from `data` starting at `offset`. The transfer is split into blocks of `NativeRpmsgHelper.BlockSize` words with `NativeRpmsgHelper.BlockDelay` milliseconds between blocks.

**Returns** `int` — The number of words actually written.

### StartReceiving()

```csharp
public static Task StartReceiving()
```

Starts the background receive loop. The loop reads whole messages from the helper endpoint and raises `NativeRpmsgHelper.DataReceived` for each. Safe to call more than once: only the first call starts a loop; subsequent calls return a completed task.

**Returns** `Task`
