
## Properties

### BackgroundColor


Button background color as `0x00RRGGBB`. Getter returns the last value set.

**Returns** `uint`

### FontSize

```csharp

```

Caption font size in pixels. Getter returns the last value set.

**Returns** `int`

### Text


**Returns** `string`

