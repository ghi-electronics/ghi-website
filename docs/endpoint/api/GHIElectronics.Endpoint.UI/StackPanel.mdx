# StackPanel Class

**Package:** `GHIElectronics.Endpoint.UI`<br/>**Namespace:** `GHIElectronics.Endpoint.UI`

WPF-style StackPanel: stacks children vertically (default) or horizontally via LVGL flex layout. `StackPanel.Spacing` is the gap between children; each child's `Widget.SetMargin` stacks on top of that.

```csharp
public class StackPanel : Widget
```
