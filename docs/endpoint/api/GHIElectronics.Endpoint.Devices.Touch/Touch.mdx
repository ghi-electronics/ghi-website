# Touch Class

**Package:** `GHIElectronics.Endpoint.Devices.Touch`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Touch`

A touchscreen on the board. This class is abstract: the library ships one concrete subclass, `Touch.InputTouch`, for touchscreens the kernel exposes at `/dev/input/eventN` (USB HID touchscreens). All other touch controllers (SPI chips like XPT2046, I2C chips like FT5x06 or GT911, custom boards) are the customer's own subclass code using the Core Spi/I2c/Gpio APIs. Interrupt-based drivers are first class: `GpioPin.ValueChanged` wakes the touch thread the moment the chip pulls the IRQ line. Subclasses raise `Touch.OnChangedEvent` by calling `Touch.RaiseChanged` from their reader loop or interrupt handler.
