# AdcController Class

**Package:** `GHIElectronics.Endpoint.Devices.Adc`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Adc`

Endpoint's analog inputs, for .NET's `System.Device.Analog`. The pins are the per-board `Adc.Pin` constants (for example `EPM815.Adc.Pin`). Opening a pin makes it an analog input; closing it puts the pin back as it was. The inputs measure 0 V to `AnalogController.VoltageReference`.
