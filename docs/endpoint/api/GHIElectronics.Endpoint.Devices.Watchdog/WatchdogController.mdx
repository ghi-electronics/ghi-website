# WatchdogController Class

**Package:** `GHIElectronics.Endpoint.Devices.Watchdog`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Watchdog`

Endpoint's watchdog, with the same API as TinyCLR. After `WatchdogController.Enable`, `WatchdogController.Reset` must be called more often than the timeout, or the board restarts. The watchdog cannot be stopped once it runs. `WatchdogController.Disable` hands it to the system, which then keeps it fed. If the program ends or crashes without `WatchdogController.Disable`, the board restarts after the timeout, also when debugging stops.
