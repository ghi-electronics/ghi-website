# DisplaySettings Class

**Package:** `GHIElectronics.Endpoint.Devices.Display`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.Display`

Everything in /config/display.json. Read with `DisplayController.GetSettings` and apply with `DisplayController.SetSettings`. Only the built-in Parallel transport has schema here; custom panels live in the customer's own `Display.DisplayController` subclass.
