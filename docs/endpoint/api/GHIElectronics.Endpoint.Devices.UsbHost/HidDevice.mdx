# HidDevice Class

**Package:** `GHIElectronics.Endpoint.Devices.UsbHost`<br/>**Namespace:** `GHIElectronics.Endpoint.Devices.UsbHost`

A HID device that is no keyboard, mouse or joystick (a sensor, a USB I/O board, a UPS...): its reports, as hidapi gives them.

```csharp
public class HidDevice : BaseDevice
```

### Remarks

Open it with the DeviceName of a HID device from `UsbHostController` ("/dev/hidraw0"). A report's first byte is its report ID: 0 for a device that does not number its reports.
