---
title: "Networking"
---

Endpoint provides full networking through .NET's standard `System.Net`
stack (sockets, HTTP/HTTPS, WebSockets, TLS). The Endpoint-specific
`GHIElectronics.Endpoint.Devices.Network` package is only for bringing the
network interface up and configuring it.

Two interface types are supported:

- **Ethernet**: the board's built-in Ethernet, or any USB Ethernet adapter.
- **Wi-Fi**: a built-in Wi-Fi module, or a USB Wi-Fi dongle.

Settings persist in `/config/network.json`. Nothing starts automatically at
boot; the application calls `Enable()` on the interfaces it wants up.

## Wi-Fi

```csharp
using GHIElectronics.Endpoint.Devices.Network;

var wifi = NetworkController.FromType(NetworkType.Wifi);

var settings = new WiFiNetworkInterfaceSettings {
    Ssid = "MyNetwork",
    Password = "secret123",
    Security = WiFiSecurityType.Wpa2,
    IsDhcpEnabled = true,
};

wifi.SetInterfaceSettings(settings);   // saves to /config/network.json
wifi.Enable();                          // brings the interface up, runs DHCP

Console.WriteLine($"Connected: {wifi.IsConnected}");
Console.WriteLine($"Interface: {wifi.Name}");

// Standard .NET info is also available
var nic = wifi.NetworkInterface;
if (nic != null) {
    foreach (var ip in nic.GetIPProperties().UnicastAddresses)
        Console.WriteLine(ip.Address);
}
```

## Ethernet

Static IP:

```csharp
using System.Net;
using GHIElectronics.Endpoint.Devices.Network;

var eth = NetworkController.FromType(NetworkType.Ethernet);

var settings = new NetworkInterfaceSettings {
    IsDhcpEnabled = false,
    Address        = IPAddress.Parse("192.168.1.50"),
    SubnetMask     = IPAddress.Parse("255.255.255.0"),
    GatewayAddress = IPAddress.Parse("192.168.1.1"),
    DnsAddresses   = new[] { IPAddress.Parse("8.8.8.8") },
};

eth.SetInterfaceSettings(settings);
eth.Enable();
```

DHCP (the common case):

```csharp
var eth = NetworkController.FromType(NetworkType.Ethernet);
eth.SetInterfaceSettings(new NetworkInterfaceSettings { IsDhcpEnabled = true });
eth.Enable();
```

## Using the network

Once an interface is enabled, use `System.Net.Http`, `System.Net.Sockets`,
`System.Net.WebSockets` or any .NET networking library exactly as you would
on a PC:

```csharp
using var http = new HttpClient();
var json = await http.GetStringAsync("https://api.example.com/status");
Console.WriteLine(json);
```
