---
title: "OPC UA"
---

OPC UA (IEC 62541) is the modern industrial interoperability standard —
secure, transport-independent, with a rich information model used
throughout factory automation, building management, and energy. Endpoint
runs the same cross-platform OPC UA libraries used on desktop and server.

Endpoint is well suited to the **client** role (reading tags from a PLC
or historian, subscribing to data changes, invoking methods) and to
**small or medium server** deployments where Endpoint exposes a focused
address space — local sensor values, a few dozen to a few hundred nodes.
Very large address spaces (thousands of nodes, high-frequency pub/sub,
many simultaneous sessions) are better suited to a dedicated server
machine than to a 256 MB embedded board.

## .NET

The reference implementation is the OPC Foundation's
[OPCFoundation.NetStandard.Opc.Ua](https://www.nuget.org/packages/OPCFoundation.NetStandard.Opc.Ua)
stack, fully supported and actively maintained.

```csharp
using Opc.Ua;
using Opc.Ua.Client;
using Opc.Ua.Configuration;

var application = new ApplicationInstance { ApplicationType = ApplicationType.Client };
await application.LoadApplicationConfiguration("MyClient.Config.xml", silent: false);
await application.CheckApplicationInstanceCertificates(silent: false);

var endpoint = CoreClientUtils.SelectEndpoint("opc.tcp://plc.example.com:4840",
                                               useSecurity: true);
var session = await Session.Create(application.ApplicationConfiguration,
    new ConfiguredEndpoint(null, endpoint), false, "Endpoint", 60_000, null, null);

var value = session.ReadValue(new NodeId("ns=2;s=Device1/Temperature"));
Console.WriteLine(value);
```

## Python

Use [asyncua](https://pypi.org/project/asyncua/), the async Python OPC
UA library (client and server).

```python
import asyncio
from asyncua import Client

async def main():
    async with Client(url="opc.tcp://plc.example.com:4840") as client:
        node = client.get_node("ns=2;s=Device1/Temperature")
        value = await node.read_value()
        print(value)

asyncio.run(main())
```

## Hosting an OPC UA server

Endpoint can also host a small OPC UA server (exposing local sensors or
a derived address space) using the same packages above. Keep the model
focused and the session count modest to stay within the board's memory
budget. For gateway patterns — translating between Modbus/CAN/sensors on
one side and OPC UA on the other — see
[Endpoint as gateway](gateway.mdx).
