## Endpoint Config

Endpoint Config is a small Windows tool for the Endpoint board. It connects
to the board **over a single USB cable** — no network, no SSH, nothing to
install on the board — and gives you one place to configure the device,
manage the apps on it, and watch the running program's output.

### Configure the device

Load, set and save the settings that live on the board's `/config`
partition, directly from your PC:

- **Wi-Fi** — SSID, password, security (WPA2 / WPA3), DHCP or static IP.
- **Ethernet** — DHCP or static IP, netmask, gateway, DNS.
- **Display** — resolution, orientation, backlight, boot logo.
- **Date & time** — set the real-time clock, pick the time zone.

The same settings can also be read and written from your application
through the Configuration API in `GHIElectronics.Endpoint.Core` — Endpoint
Config just gives you a GUI for the same JSON files.

### Manage applications

An app on the board is a folder in `/data/apps/`. From Endpoint Config
you can:

- **Upload** an app folder from your PC to the board.
- **Download** an app from the board back to your PC (to keep a copy, or
  to clone it to another board).
- **Start** / **Stop** the running app.
- **Enable** / **Disable** run-at-boot (the app that starts after
  power-on).
- **List files** that make up an app.
- **Erase** an app.

### Device info and utilities

- Boot source (SD card or eMMC), firmware version, .NET version, status.
- **Ping** the board, **Reboot** the board.
- **Live Output** — stream the running app's stdout, including the last
  lines it printed before you connected.
