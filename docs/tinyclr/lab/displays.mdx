# Displays

Print text, draw shapes, and graph live sensor readings from C#. The FEZ Bit uses its built-in 1.8" color display; on the FEZ Flea you'll wire up a common I²C OLED and learn what I²C is along the way.

:::note[Parts not in the kit]
FEZ Bit: nothing extra — the display is built in. FEZ Flea: a common SSD1306 I²C OLED display, available from most electronics suppliers.
:::
