# Distance Sensor

Measure distance with the HC-SR04 ultrasonic sensor: send a ping, time how long the echo takes to come back, and turn that time into centimeters using the speed of sound.

And a radar? A radar is nothing more than a distance sensor that moves. Mount the sensor on the servo from the [Servo Motor](servo-motor.mdx) lesson, take a reading at each angle, and you're sweeping the room.
